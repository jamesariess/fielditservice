# Dark Mode Audit

Confirmed in the supplied screenshots: Commands, Tools, and Equipment Brand.
Issues include light detail panels, dark text on dark surfaces, filter buttons,
copy controls, table headers, and table rows.

Additional pages with the same inline neutral color patterns (source audit):

- Dashboard
- Troubleshooting and Submit Steps
- Profile
- Tickets
- Equipment
- Notifications
- Team Chat
- Admin Departments
- Admin Knowledge
- Admin Ticket Management
- Admin Settings
- Admin Audit
- Admin Equipment
- Admin Statistics
- Admin Troubleshooting
- Admin Users

The shared dark-compat stylesheet corrects neutral text, surfaces and borders
inside the authenticated content area and modal overlays. Reference pages also
have targeted filter, table, code and tool-title rules. Primary buttons retain
their white text; warning panels retain their warning meaning.

These additional pages are source findings, not a claim that every live page
and modal has been visually tested. Authentication, live records, and the
hosting database are required for a complete production audit.
